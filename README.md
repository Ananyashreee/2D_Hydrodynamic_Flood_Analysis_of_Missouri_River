# 2D-Hydrodynamic-Flood-Analysis-of-Missouri-River-


A 2D unsteady-flow hydraulic model of the Missouri River mainstem developed to simulate channel conveyance, levee overtopping risk, velocity distributions, and floodplain inundation extent.

---

## 📌 Project Summary
* **Study Area:** Missouri River 
* **HEC-RAS Version:** 6.3.1+
* **Model Configuration:** 2D Unsteady Flow Analysis
* **Horizontal Datum:** NAD83 / UTM Zone 15N (EPSG:26915) 
* **Vertical Datum:** NAVD88 (US Survey Feet / Meters)
* **Primary Objective:** Floodplain inundation mapping, rating curve calibration, and flood risk assessment.
